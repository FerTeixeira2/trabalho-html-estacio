# 🖥️ Controle de Estoque - Hardware & Periféricos

Este projeto consiste em um protótipo de sistema web totalmente desenvolvido em **HTML5 puro** (sem CSS/JS/Backend), focado em simular a estrutura e navegação de uma aplicação para gestão de estoque de uma loja de informática.

## 🚀 Funcionalidades
- **Tela de Login:** Acesso inicial do sistema.
- **Listagem de Produtos:** Exibição dos itens em estoque com imagem, quantidade e preço.
- **Cadastro e Edição de Produtos:** Formulários completos para inclusão e alteração de itens.
- **Cadastro de Categorias:** Organização de periféricos, processadores, memórias, etc.
- **Gerenciamento de Usuários:** Listagem de operadores/administradores com opção de edição.
- **Suporte/Contato:** Página para envio de dúvidas ou suporte técnico.

## 📂 Estrutura de Pastas
- `index.html`: Página inicial/Login
- `/imagens`: Repositório de imagens dos produtos
- `/paginas`: Páginas secundárias do sistema (produtos, formulários e usuários)
